# WEFLASH 화장실 위급상황 감지 시스템

제24회 임베디드SW경진대회 제출용 소스코드 저장소입니다.

WEFLASH는 카메라 없이 C1001과 LD2410C 밀리미터파 센서로 화장실 한 칸의
재실, 움직임, 낙상 의심, 낮은 자세와 장시간 무반응을 감지합니다. 천장 센서부와
외부 제어부는 ESP-NOW로 통신하며, 위급상황 발생 시 BF395 경광등·사이렌과
휴대폰 로컬 웹 화면으로 알립니다.

> 연구·교육 및 대회 시연용 시제품이며 의료기기, 소방설비 또는 법정
> 비상경보장치를 대체하지 않습니다.

## 주요 기능

- 카메라·마이크 없이 밀리미터파 센서값만 처리
- C1001 낙상·정지 감지와 LD2410C 재실·움직임 감지 결합
- ESP-NOW 기반 천장부-외부 제어부 통신
- 문센서와 유선 SOS 버튼
- BF395 12V 경광등·사이렌 릴레이 제어
- 휴대폰 로컬 웹 UI 상태 확인·시험·경보 해제
- HMAC-SHA256 인증 태그를 이용한 패킷 검증

## 확정 펌웨어 조합

| 장치 | 버전 | 경로 |
|---|---:|---|
| 천장 센서부 | 3.5.3 | `firmware/final/ceiling_final_v35/` |
| 외부 제어부 | 3.5.0 | `firmware/final/external_final_v35/` |

두 펌웨어는 패킷 v2, ESP-NOW 채널 6, 40바이트 패킷과 같은 HMAC 키를
사용합니다. 외부부 3.5.0은 천장부 3.5.3과 호환됩니다.

## 소스 구성

```text
firmware/
├── final/          # 실제 설치·시연용 최종 펌웨어
└── diagnostics/    # 센서·입력·릴레이·ESP-NOW 개별 시험 코드
third_party/
└── DFRobot_HumanDetection/  # C1001 UART 오류 판별 안전 패치 포함
```

실제 설치에는 `firmware/final`의 두 코드만 사용합니다. ESP-NOW 진단 송신·수신
스케치는 서로만 사용하는 구형 시험 패킷이므로 최종 코드와 혼용하지 않습니다.

## 핀 배치

### 천장 센서부

| 부품 | 센서 핀 | ESP32-S3 |
|---|---|---|
| C1001 | TX | GPIO4(RX) |
| C1001 | RX | GPIO5(TX) |
| LD2410C | TX | GPIO16(RX) |
| LD2410C | RX | GPIO17(TX) |
| 두 센서 | VCC/GND | 5V/GND 공통 레일 |

### 외부 제어부

| 부품 | 연결 |
|---|---|
| 문센서 2심 | GPIO4/GND, `INPUT_PULLUP` |
| SOS 버튼 2심 | GPIO5/GND, `INPUT_PULLUP` |
| 릴레이 IN1 | GPIO17, H 트리거 |
| 릴레이 VCC/GND | 5V/GND |
| BF395 | 릴레이 COM/NO를 통한 12V 스위칭 |

BF395를 DC-DC 5V 출력에 연결하지 마십시오.

## 개발·컴파일 환경

- Arduino IDE 2.x 또는 Arduino CLI 1.5.1
- ESP32 Arduino Core 3.3.11
- 보드: ESP32S3 Dev Module (`esp32:esp32:esp32s3`)
- 수정 라이브러리: `third_party/DFRobot_HumanDetection`

공식 DFRobot 라이브러리에는 프로젝트에서 사용하는 `getFallStateChecked()`가
없습니다. 이 저장소의 패치 라이브러리를 설치해야 천장부 코드가 컴파일됩니다.

## 설정과 업로드

1. 두 최종 스케치 폴더의 `project_config.example.h`를 `project_config.h`로 복사합니다.
2. 두 설정 파일에 동일한 32바이트 HMAC 키를 입력합니다.
3. 외부부 Wi-Fi AP 비밀번호를 8자 이상으로 설정합니다.
4. 수정된 DFRobot 라이브러리를 Arduino 라이브러리 폴더에 설치합니다.
5. 외부 제어부, 천장 센서부 순서로 업로드합니다.
6. 빈 공간에서 C1001 초기화가 끝날 때까지 약 30~60초 기다립니다.
7. 천장 시리얼의 `[C1001] 준비 완료`와 모바일 화면의 센서 정상을 확인합니다.

실기에서 C1001 낙상 확정 2초 설정은 저장되지 않고 60초 기본값이 유지됐습니다.
최종 천장 코드는 저장이 확인된 5초 설정을 사용하고, 재시작 후 `5/5초`인지
검증합니다.

천장부 시리얼 명령:

| 명령 | 기능 |
|---|---|
| `A` | 실제 센서 자동 판정 |
| `1` | 강제 경보 시험 |
| `0` | 강제 정상 시험 |
| `S` | 현재 센서 원시값 출력 |
