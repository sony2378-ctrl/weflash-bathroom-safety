# 화장실 위급상황 감지 시스템 WEFLASH

제24회 임베디드SW경진대회에 출품한 WEFLASH의 소스코드입니다.

화장실은 사생활 문제 때문에 카메라를 설치하기 어렵고, 안에서 혼자 쓰러지거나
움직이지 못하는 상황이 생겨도 밖에서는 바로 알기 어렵습니다. 저희는 이 문제를
해결하기 위해 카메라 대신 밀리미터파 센서 2개를 사용했습니다.

천장에 설치한 센서 장치가 사람의 재실 여부와 움직임, 낙상 의심 상태를 확인하고,
위급상황으로 판단되면 화장실 밖의 경광등과 사이렌을 작동시킵니다. 의식이 있는
경우에는 화장실 안의 SOS 버튼을 눌러 바로 도움을 요청할 수도 있습니다.

## 작품 구성

### 천장 감지 장치

- ESP32-S3
- C1001 낙상 감지 센서
- LD2410C 재실·움직임 감지 센서
- 12V 입력과 DC-DC 5V 전원

### 외부 알림 장치

- ESP32-S3
- 문 열림 감지 센서
- 유선 SOS 버튼
- 릴레이
- BF395 경광등·사이렌
- 휴대폰 상태 확인 및 경보 해제 화면

천장 감지 장치와 외부 알림 장치는 ESP-NOW로 통신합니다. 인터넷이 없어도 가까운
거리에서 동작하며, 전송 데이터에는 HMAC 인증값을 넣어 잘못된 패킷이 경보로
처리되지 않도록 했습니다.

## 핀 연결

### 천장 감지 장치

| 센서 | 센서 핀 | ESP32-S3 |
|---|---|---|
| C1001 | TX | GPIO4(RX) |
| C1001 | RX | GPIO5(TX) |
| LD2410C | TX | GPIO16(RX) |
| LD2410C | RX | GPIO17(TX) |
| 두 센서 | VCC/GND | 5V/GND 공통 전원 |

### 외부 알림 장치

| 부품 | 연결 |
|---|---|
| 문 열림 감지 센서 | GPIO4/GND |
| SOS 버튼 | GPIO5/GND |
| 릴레이 입력 | GPIO17 |
| 릴레이 전원 | 5V/GND |
| BF395 경광등·사이렌 | 릴레이 COM/NO를 통한 12V 연결 |

BF395는 12V 제품이므로 DC-DC의 5V 출력에 연결하면 안 됩니다.

## 사용한 개발 환경

- Arduino IDE 2.x
- ESP32 Arduino Core 3.3.11
- ESP32S3 Dev Module
- DFRobot Human Detection 라이브러리 1.0.0 기반 수정본

C1001 라이브러리의 기존 함수만으로는 정상적인 낙상값 0과 UART 통신 실패를
구분하기 어려웠습니다. 그래서 통신 성공 여부를 함께 확인하는
`getFallStateChecked()` 함수를 추가했습니다. 천장 감지 장치 코드를 컴파일할 때는
이 저장소의 `third_party/DFRobot_HumanDetection` 라이브러리를 사용해야 합니다.

## 업로드 전에 할 일

1. 각 최종 코드 폴더의 `project_config.example.h`를 `project_config.h`로 복사합니다.
2. 두 설정 파일에 같은 32바이트 HMAC 키를 입력합니다.
3. 외부 알림 장치의 Wi-Fi 비밀번호를 8자 이상으로 설정합니다.
4. 외부 알림 장치 코드를 먼저 업로드합니다.
5. 천장 감지 장치 코드를 업로드합니다.
6. 전원을 켠 뒤 C1001 준비가 끝날 때까지 약 30~60초 기다립니다.

C1001 낙상 확정 시간을 2초로 설정했을 때 실제 센서에는 값이 저장되지 않고 60초가
유지되는 문제가 있었습니다. 최종 코드에서는 저장이 확인된 5초를 사용하고, 센서를
재시작한 뒤 실제 저장값이 `5/5초`인지 다시 확인합니다.

## 천장 감지 장치 시험 명령

| 입력 | 기능 |
|---|---|
| `A` | 실제 센서값을 사용하는 자동 감지 |
| `1` | 경보 강제 작동 |
| `0` | 강제 정상 상태 |
| `S` | 현재 센서값 출력 |

## 참고사항

- 실제 비밀번호와 HMAC 키가 들어가는 `project_config.h`는 GitHub에 올리지 않았습니다.
- 공개된 예시 비밀번호와 키는 실제 설치에 그대로 사용하면 안 됩니다.
- 센서값은 천장 높이와 화장실 구조에 따라 달라지므로 설치 장소에서 다시 확인해야 합니다.
- 이 작품은 대회 시연용 시제품이며 의료기기나 공식 비상경보 설비를 대신하지 않습니다.
