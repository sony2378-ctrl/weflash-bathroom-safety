# WEFLASH 최종 펌웨어 세트 v3.5.3

현재 실기 확인이 끝난 배포 조합은 아래 한 쌍이다.

| 장치 | 파일 | 내부 표시 버전 | 상태 |
|---|---|---:|---|
| 천장 센서부 | `ceiling_final_v35/ceiling_final_v35.ino` | 3.5.3 | C1001 5초 저장 확인 수정 포함 |
| 외부 제어부 | `external_final_v35/external_final_v35.ino` | 3.5.0 | v3.5.3 천장부와 그대로 호환 |

외부부는 이번 C1001 수정의 대상이 아니므로 3.5.0을 유지한다. 이미 외부부 시험이
끝났다면 다시 업로드할 필요가 없다. 두 코드는 `PACKET_VERSION = 2`, ESP-NOW
채널 6, 40바이트 패킷 구조와 HMAC 키가 같아야 한다.

이 폴더만 실제 설치용이다. `../diagnostics/`의 부품 시험 코드를 최종 코드와
섞어서 업로드하지 않는다.

## 현재 배선

### 천장부

- C1001 TX -> GPIO4, C1001 RX -> GPIO5
- LD2410C TX -> GPIO16, LD2410C RX -> GPIO17
- 두 센서 모두 5V/GND 공통 전원 레일

### 외부 제어부

- 문센서 -> GPIO4/GND (`INPUT_PULLUP`)
- SOS -> GPIO5/GND (`INPUT_PULLUP`)
- 릴레이 IN1 -> GPIO17, VCC -> 5V, GND -> GND
- 릴레이 H 트리거 기준

## 업로드 순서

1. 외부 제어부 코드를 외부 ESP32-S3에 업로드한다.
2. 천장부 코드를 천장 ESP32-S3에 업로드한다.
3. 외부 시리얼 모니터를 115200 baud로 열어 ESP-NOW 수신을 확인한다.
4. 휴대폰을 `WEFLASH-ALARM`에 연결한다. 비밀번호는 외부부의 로컬 `project_config.h` 값을 사용한다.
5. `http://192.168.4.1`을 연다.
6. 빈 화장실에서 전원을 넣고 C1001 초기화가 끝날 때까지 약 30~60초 기다린다.
7. 천장 시리얼의 `[C1001] 준비 완료`와 모바일 화면의 C1001 `정상`을 확인한 뒤 시연을 시작한다.

초기화 중에는 ESP-NOW와 LD2410C가 정상이더라도 C1001이 `대기/오류`, 원시값
`-1`로 표시될 수 있다. 준비 완료 뒤에도 계속 오류라면 5V/GND와 TX/RX를 점검한다.

## 실기 확정 C1001 설정

정상 초기화 시 시리얼에 아래 값이 표시되어야 한다.

```text
모드=1/1, 높이=240/240 cm, 낙상지연=5/5초, 정지=15/15초, 민감도=3/3
```

- `5초`: C1001 센서 내부 낙상 확정 시간
- `3회`: 낙상 시간 설정 명령과 저장값 조회의 최대 반복 횟수
- `10초`: 초기화 실패 후 전체 연결을 다시 시도하는 간격
- `15초`: 마지막 정상 C1001 샘플을 유효하게 보는 시간

실기에서 2초 설정은 저장되지 않고 60초 기본값이 남았다. 따라서 최종 코드와
C1001 진단 코드는 모두 저장이 확인된 5초를 사용한다. C1001의 `움직임값/범위`는
센티미터가 아니라 0~100 움직임 강도값이다.

## 전체 시험

처음에는 BF395를 분리하거나 아주 짧게 시험한다.

1. 천장부 시리얼에 `1`: 강제 경보 및 릴레이 ON 확인
2. 휴대폰에서 경보 해제
3. 천장부 시리얼에 `0`: 강제 정상 확인
4. 천장부 시리얼에 `A`: 실제 센서 자동 판정 복귀
5. 문센서 열림/닫힘 표시 확인
6. SOS 버튼 경보 및 모바일 해제 확인
7. 서기, 착석, 천천히 낮아지기, 바닥에 누워 정지하기의 실제 센서값 확인

천장부 명령은 `A=자동`, `1=강제 경보`, `0=강제 정상`, `S=현재값`이다.

## 설치 후 조정값

- 천장 높이: 천장 코드의 `C1001_INSTALL_HEIGHT_CM`
- 낮은 자세 기준: 천장 코드의 `LOW_POSITION_MIN_CM`
- 발표/실사용 시간: 외부 코드의 `CONTEST_DEMO_MODE`

두 스케치 폴더의 `project_config.example.h`를 `project_config.h`로 복사하고 동일한 HMAC 키를 설정한다. 실제 `project_config.h`는 Git에 포함하지 않는다.

`CONTEST_DEMO_MODE = 1`은 장시간 무반응 15초인 발표용이다. 일반 운용 시험은 0으로 바꾸면 300초가 된다.

전원 투입 직후 C1001 준비가 끝나기 전에 사람이 들어가 오래 정지하면 발표용
15초 무반응 경보가 먼저 발생할 수 있다. 반드시 빈 칸에서 준비 완료 후 시작한다.
